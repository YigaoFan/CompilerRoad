**** 效率优化之项目进度记录
需要个工具记录项目进度，然后也需要记录下工作日志。考量下来，Emacs 的 org mode 比较合适。一是格式简单，二是各种折叠、总览效果不错。缺点是各种快捷键多得很，根本记不住。
所以来到 Emacs 环境的搭建，由于 Emacs 在 Windows 下显示效果不怎么样，AI 也说 Linux 下效果比较好，推荐安装个 WSL。
***** Emacs 版本选择：Doom Emacs
这次就不从原始的 Emacs 开始配置了，直接用别人打包好的配置。AI 说 Doom Emacs 的社区活跃度逐渐盖过 Spacemacs。所以选择了 Doom Emacs。Doom 有个优点，就是按空格后窗口下方会提示各种快捷键。跟飞书的 / 类似。
***** WSL 系统的选择：Debian
要求尽量资源占用小。在 WSL 支持的系统里选择了 Debian。
***** 连接 Debian：Tabby
Tabby 的 UI 比较好看。但是 emacs -nw 有个界面刷新的问题：类似于某一行刷新了，但是其它行还是老样子，要按个 Ctrl+l 刷新下整个终端界面。于是，只能使用 emacs & 调用 GUI 来显示。刚开始打开这个的 GUI 界面，只有任务栏显示有个窗口，但是窗口也看不到。后来重启下 WSL 又显示正常了，只能说这个东西刚装上会抽风。
